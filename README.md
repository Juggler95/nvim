This nvim config does use kickstart.nvim as a base but I have made changes to the config to make it my own.

### Install
This is using commands that should work on linux and mac
Make sure to backup your current config if you have one.
`mv ~/.config/nvim ~/.config/nvim.bak`
`mkdir ~/.config/nvim`
`git clone https://github.com/Juggler95/nvimV2.git ~/.config/nvim`

### Needed Programs
- git
- fd
- ripgrep
- node, npm
- Nerd Font (recommended)
